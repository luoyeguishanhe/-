# 语音识别与字幕 · Windows 便携测试版

1. 将 ZIP **完整解压**到一个文件夹，不要在压缩包预览中运行。
2. 双击 `SubtitleApp.exe`。电脑无需另外安装 Python、pip 或 FFmpeg。
3. 首先可点击“选择视频并生成字幕”识别，再导出、校对字幕；“翻译与封装…”可处理已有 SRT。识别模型和字幕偏移在“更多设置”中。
4. “开始识别电脑声音”默认使用程序同目录 `cache` 下的独立临时会话，关闭或开始下次任务时清理。勾选“保留录音 WAV 并自动保存字幕”后才需要选择保存位置。缓存目录可在“更多设置”中修改。

请保留 EXE 旁的 `_internal` 和 `models` 文件夹，不要单独复制 EXE。升级时将新版解压到新目录，保留自己的视频、字幕和用量报告。

此份便携包附带 small 模型，可离线识别。base、medium 未附带，选择它们时需要已有缓存或联网下载。使用云端翻译仍需配置服务地址、模型与 API Key；本地 Ollama 仍需要单独安装并启动。

软字幕封装输出 MKV，字幕可以开关，原视频保持不变；没有烧录功能。Token 和费用统计在“翻译与封装”窗口内，关闭前可导出用量报告。使用细节见 `docs` 文件夹。

程序日志保存在 `%LOCALAPPDATA%\SubtitleApp\logs\app.log`。启动异常时，请保留完整目录并查看日志。

当前是 Windows 64 位便携测试版，尚不是带安装向导和自动更新的安装包，正式产品名未确定。
