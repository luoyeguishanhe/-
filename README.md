# 字幕工坊（界面试用版）

这是一款使用本地语音模型识别声音并生成字幕的应用。目前支持 Windows 系统声音录制、本地视频导入、语音检测、TXT/SRT 导出、视频字幕校对、外部模型翻译、直播翻译字幕悬浮框和 MKV 软字幕封装。

## 启动开发版

已支持 Windows 64 位 EXE 便携包：完整解压后双击 `SubtitleApp.exe`，保留 `_internal` 和 `models` 文件夹；带 small 模型的版本可离线识别，无需安装 Python。打包配置及重新构建步骤见 [Windows 打包说明](docs/Windows打包.md)。成品 ZIP 单独交付，不提交 Git。

需要 Python 3.11 或更新版本。在项目目录中运行：

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -e .
.venv\Scripts\python -m subtitle_app
```

在窗口左侧选择视频实际使用的输出设备和原声语言，再点击“开始识别电脑声音”。默认无需选择保存位置：录音写入程序目录下的 `cache` 会话文件夹，结束后可试听校对，关闭程序或开始下一次任务时自动删除该文件夹。若勾选“保留录音 WAV 并自动保存字幕”，开始时会让你选择 WAV 保存位置，完成后自动在旁边生成 TXT/SRT。程序先在后台加载本地 Whisper 模型；**首次使用所选模型会先下载，模型就绪后才开始录音**。默认使用 `small`；点击“更多设置”可改为速度优先的 `base` 或用于对比的较大模型 `medium`，也可更改缓存目录。更大模型在 CPU 上通常更慢，是否更准需要按音频实测。已知原声是中文时，可把“原声语言”设为“中文”，避免每段重新判断语言。播放视频时观察音量条，语音结束并出现约 1 秒静音后，识别文字会逐段显示在窗口中。结束后点击“结束识别”，最后一段语音也会处理。

录音使用 Windows WASAPI loopback，仅采集选中输出设备正在播放的声音，不采集麦克风。程序会优先混合实际有声音的声道，再持续重采样；缓存或保存的 WAV 均为 **16 kHz、单声道、16 位 PCM**。WebRTC VAD 负责语音分段，faster-whisper 在 CPU 上识别原文；中文识别结果统一转换为简体字。临时模式需手动导出文字或字幕；勾选保留录音后会自动在 WAV 旁保存 UTF-8 TXT 和 SRT。

## 看直播时显示翻译字幕

1. 选择直播实际使用的声音输出设备和原声语言。点击“翻译服务设置…”：选择千问、Ollama 或自定义兼容接口，填写模型、地址和云端所需的 API Key。Ollama 需要预先启动服务并拉取所选模型；Key 仅保存在本次运行的内存中。
2. 点击“开始直播翻译字幕”。程序加载语音模型后开始采集系统声音；半透明字幕框会显示在屏幕前方，可按住文字区域拖动。点“隐藏”可暂时收起，再点主窗口“显示字幕框”恢复。
3. 结束时点击“结束识别”，程序会处理最后一段语音，再完成排队中的翻译。默认使用临时录音缓存，不询问 WAV 保存位置；关闭程序或开始新任务时清理缓存。原文可从主窗口导出 TXT/SRT。

直播模式约在 0.6 秒静音后切出语音片段，最长约 5 秒；实际字幕延迟还包括语音模型推理和翻译接口响应，网络或本地模型较慢时会增加延迟。翻译速度跟不上时，为保持直播字幕接近当前声音，等待队列可能跳过旧片段。云端只收到识别出的文字，不会收到视频或音频；接口需支持 `/chat/completions`，并按要求返回带编号的 JSON 译文。主窗口显示接口返回的 token 用量，未返回用量的调用会单独计数。直播悬浮框只显示当前译文，不自动导出译文 SRT；需要成片字幕时使用“翻译与封装…”处理原文字幕。

## 保存文字和字幕

1. 临时识别时点击“结束识别”，等待最后的结果，然后点击“保存 TXT…”或“导出 SRT…”选择保存位置。TXT 是纯识别文字，SRT 是带起止时间的字幕。
2. 若开始前勾选了保留录音，点击“停止并保存”后，程序会自动在 WAV 旁保存同名 `.txt`、`.srt`；已有同名文件时会加编号，保留旧文件。
3. 想另存到其他位置，也可点击“保存 TXT…”或“导出 SRT…”。存在文件时会询问是否替换；保存失败时文字仍留在窗口，可以重试。
4. 需要同步到原视频时，调整“字幕偏移（秒）”，再重新导出 SRT。正数延后、负数提前；修改偏移不会自动改写之前的文件。

SRT 使用模型的词语时间戳断句，并加上片段在原录音中的位置；Silero 移除的配乐或静音间隔会保留在时间轴上。**识别处理耗时不会写进字幕时间。**时间是模型估计值，仍可有误差；极少数缺少词语对齐的片段会回退到模型给出的整段时间。

默认偏移 `0` 与当前录音同步，包括临时录音。例如从原视频第 30 秒开始录音，导出配原视频用的字幕时填 `+30`；若先录音 5 秒才从视频开头播放，则填 `-5`。播放时请保持正常速度并连续播放；系统音频录制无法跟踪播放器的暂停、跳转或倍速，单个全局偏移也无法修复这种时间轴变化。

勾选保留录音时，录音或识别过程中有片段被跳过、识别被中断，已有结果会另存为带 `-partial` 的文件，表示可能不完整。临时模式不自动保存文字或字幕；需要保留时请点击“保存 TXT…”或“导出 SRT…”，关闭前如有未保存文字会提示。系统录音识别期间关闭窗口，会先停止录音、等待最后结果完成，再清理临时缓存。程序目录不可写时，默认缓存位置会改为用户本地应用数据目录；自定义目录不可写时会提示重新选择。

## 本地视频直接生成字幕

1. 选择原声语言，点击“选择视频并生成字幕”。需要更换识别模型时，打开“更多设置”；默认 small。可选择 MP4、MKV、MOV、AVI、WebM 等 PyAV 能解码的文件。
2. 程序在后台读取第一条音轨并识别，无需播放视频、不使用系统录音设备。窗口显示处理进度，期间可以点击“取消处理”。
3. 完成后，自动在视频旁生成同名 TXT/SRT。已有文件会加编号另存，保留以前的字幕；也可以使用导出按钮另存。

视频模式默认字幕偏移为 0：音频帧时间戳会映射到视频文件的时间轴，保留音轨开始前的无声时间和音轨中的时间间隔。程序流式转换为 16 kHz 单声道，每段识别完成后再继续读取，不通过实时录音队列，因此不会因为文件解码太快而跳过片段。无需额外安装 FFmpeg 命令行程序。

取消时需要等待当前模型加载或当前识别片段返回，窗口仍可响应。已完成的结果会保存为带 `-partial` 的文件；关闭正在处理视频的窗口也会请求取消，并等已有结果保存后退出。无音轨或文件损坏时会显示原因。多音轨文件当前默认第一条音轨，尚未提供音轨选择；模型时间戳仍可能需要人工微调。

## 视频预览与字幕校对

1. 本地视频或录音识别结束后，点击“预览与校对…”。左侧预览媒体，右侧显示字幕列表；播放时字幕显示在画面下方。
2. 点击一条字幕可跳转到开始位置。使用“播放 / 暂停”和进度条试听。
3. 在右下方修改文字、开始秒数或结束秒数，点击“应用本条修改”。切换条目或保存时也会自动应用当前输入；时间错误时保留输入并提示原因。
4. 可以暂停在合适位置，点击“当前播放位置设为开始”或“设为结束”，再应用。时间精确到 0.001 秒；结束必须晚于开始，各条字幕不能重叠，文字不能为空。
5. 点击“另存校对版 SRT…”，默认名称为“视频名-校对.srt”。若文件已存在，请改用新文件名。原视频、原识别 TXT/SRT 均保留；校对版只保存 SRT。

关闭或按 Esc 时，有未保存修改会询问是否丢弃。同一次会话重新打开校对窗口，会保留上次已保存的校对结果；重新识别或调整主窗口全局偏移后，校对窗口从原识别结果重新建立。当前还不能导入已有 SRT 恢复校对，退出程序前请保存。

主窗口偏移会在进入校对时应用一次，校对窗口中的时间即实际导出时间。播放使用 PyQt6 自带的 QtMultimedia，无需另装播放器；录音文件只有声音、没有视频画面。预览解码支持与 PyAV 识别支持可能不同；无法播放时仍可编辑导出，或先将视频转换为 H.264/AAC MP4。字幕当前显示在预览画面下方，尚未写入原视频。

## 字幕翻译与软字幕封装

点击主窗口“翻译与封装…”，或在校对窗口中点击同名按钮。可以带入当前字幕，也可导入已有 UTF-8 SRT，无需重新识别。主窗口带入原识别字幕与全局偏移；校对窗口带入已应用的校对结果。导入外部 SRT 时按其自身时间，不再叠加主窗口偏移。

### 生成可开关字幕的视频

1. 选择原视频和字幕，确认字幕对应所选视频。
2. 在下拉框选择“原文字幕”或完成翻译后的“译文字幕”。
3. 点击“封装为带字幕的 MKV…”，选择新文件名，等待完成。
4. 在支持 MKV/SRT 的播放器中打开新视频，选择字幕轨道，可开关字幕。

封装使用 `imageio-ffmpeg` 提供的 FFmpeg，无需自己配置 PATH。视频、全部音轨直接复制，不重新编码；保留章节和可复制的元数据，输出只使用当前选中的一条字幕，不带入源文件原有字幕轨或附件。遇到 MKV 无法直接容纳的编码会报错。取消或失败时清理本任务临时文件，原视频和已有目标文件保留。没有烧录功能。

### 使用外部模型翻译

1. 选择翻译服务：千问云端（中国内地）、Ollama 本地，或自定义兼容接口。
2. 填写地址、模型名称、API Key。地址为支持 `/chat/completions` 的 API 基址；Ollama 默认 `http://127.0.0.1:11434/v1`，本地无鉴权时 Key 可空，需事先启动服务并准备对应模型。
3. 选择目标语言（默认简体中文），点击“开始翻译原文字幕”。仅字幕文字发送到指定服务，不上传音频和视频；Key 不写入配置文件，关闭工具窗口即清除。
4. 译文完整返回后，可另存 SRT，或选择“译文字幕”封装视频。原始字幕始终保留，模型不能修改时间轴。

默认每次翻译 12 条。模型必须能按提示返回带编号的 JSON；若格式不正确，可减少每批条数或换用更擅长遵循格式的模型。取消需等待当前请求结束（单次超时 90 秒），已完成批次保留；失败或取消后的译文可另存带 `partial` 的 SRT，暂不允许封装为完整译文视频。重启翻译会从原文重新开始，不自动续传或自动重试。

工具显示本次翻译的输入、输出、已知合计 token 以及当前工具窗口的累计用量。勾选“启用费用估算”，按服务商报价填写每百万输入/输出 token 单价，选择人民币或美元，即可显示本次及窗口累计费用；未设价与明确填 0 分别表示未知价格和免费。修改单价只用于下次翻译，切换服务或编辑模型名/地址后需重新启用计价。不同币种分开累计，不自动换汇。

服务未返回的用量，以及超时等未取得用量的请求，都标为未知，不当作零；费用只显示已知部分。缓存折扣、阶梯价和赠送额度未自动纳入，实际费用以服务账单为准。可点击“导出用量报告…”保存 JSON（含模型、接口、时间、用量和单价，不含 Key 或字幕）；累计范围是当前工具窗口，关闭后不自动保留历史。详见 [Token 用量与费用](docs/Token用量与费用.md)。

外部模型接口通过本机模拟 HTTP 服务验证；实际云端或本地模型需要用户配置后验证，当前没有使用个人 API Key 测试。批量翻译在“翻译与封装…”窗口使用；直播逐句翻译在主窗口使用。

详细过程见 [字幕封装与模型翻译入门](docs/字幕封装与模型翻译入门.md)。

如果识别结果不理想，系统录音时先试听保存的 WAV：若 WAV 本身很小声、失真或缺词，先检查输出设备和音量；若 WAV 清晰而文字错误，使用 `small`、指定原声语言并观察是否仍有问题。配乐、朗诵停顿和生僻词仍可能影响 VAD 与 ASR，当前版本尚未做伴奏分离或逐字校对。

后续将按功能逐步复用 [LiveTranslate](https://github.com/TheDeathDragon/LiveTranslate) 的实现，并保留所复用代码的 MIT 版权及许可声明。目前的界面骨架未复制其源代码。

## 开发方向

1. 改进直播字幕延迟、错词修正和显示体验。
2. 支持常见云端及本地翻译模型，显示 token 用量和费用。
3. 完善字幕校对与封装；烧录按当前计划暂缓。
4. 简化设置、完善界面和 Windows 安装包。

窗口标题“字幕工坊”是当前界面方案；EXE 文件名和内部包名仍为 `SubtitleApp`，正式产品名称尚未确定。

## 离线模型对比

已支持对同一批 WAV 依次比较 small、medium：保留逐段文字、识别耗时、模型配置和参考字错误率，生成可在浏览器打开的 `report.html`。参考文字未核对时明确标为草稿；校对后可以重新评分而无需再次运行模型。

复制 `benchmark.example.json` 为 `benchmark.local.json`，填写录音和参考 TXT 路径后，双击 `compare-models.cmd`。录音、个人测试清单、参考草稿与结果目录默认不提交到 Git。

详细操作、名词解释和实现过程见 [模型对比入门](docs/模型对比入门.md)。
