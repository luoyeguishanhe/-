# 实时中文字幕应用（开发中）

这是一款计划捕获 Windows 系统音频、结合本地语音模型和外部大模型进行实时翻译的字幕应用。面向普通用户，后续还计划支持本地视频字幕导出。目前已支持系统声音录制、语音检测和本地语音识别；翻译、字幕悬浮显示和字幕导出尚未接入。

## 启动开发版

需要 Python 3.11 或更新版本。在项目目录中运行：

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -e .
.venv\Scripts\python -m subtitle_app
```

在窗口中选择视频实际使用的输出设备、识别模型和原声语言，再点击“开始录音与识别”并选择 WAV 保存位置。程序先在后台加载本地 Whisper 模型；**首次使用所选模型会先下载，模型就绪后才开始录音**。默认选择准确率更高但 CPU 处理更慢的 `small`；`base` 速度更快，中文准确率通常较低。已知原声是中文时，可把“原声语言”设为“中文”，避免每段重新判断语言。播放视频时观察音量条，语音结束并出现约 1 秒静音后，识别文字会逐段显示在窗口中。结束后点击“停止并保存”，最后一段语音也会处理。

录音使用 Windows WASAPI loopback，仅采集选中输出设备正在播放的声音，不采集麦克风。程序会优先混合实际有声音的声道，再持续重采样；保存的 WAV 是 **16 kHz、单声道、16 位 PCM**。WebRTC VAD 负责语音分段，faster-whisper 在 CPU 上识别原文。当前尚不翻译成中文，也不保存文字稿；关闭窗口后，识别文字不会保留。

如果识别结果不理想，先试听保存的 WAV：若 WAV 本身很小声、失真或缺词，先检查输出设备和音量；若 WAV 清晰而文字错误，改用 `small`、指定原声语言并观察是否仍有问题。配乐、朗诵停顿和生僻词仍可能影响 VAD 与 ASR，当前版本尚未做伴奏分离或逐字校对。

后续将按功能逐步复用 [LiveTranslate](https://github.com/TheDeathDragon/LiveTranslate) 的实现，并保留所复用代码的 MIT 版权及许可声明。目前的界面骨架未复制其源代码。

## 开发方向

1. 接入系统音频采集、语音识别和实时翻译，并显示清晰的运行状态。
2. 支持常见云端及本地翻译模型，显示 token 用量和费用。
3. 基于视频音轨时间轴导出校时字幕，再支持字幕封装与烧录。
4. 简化设置、完善界面和 Windows 安装包。

正式产品名称尚未确定，当前包名仅用于开发。
