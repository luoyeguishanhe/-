# 实时中文字幕应用（开发中）

这是一款捕获 Windows 系统音频、使用本地语音模型识别文字的字幕应用。目前支持系统声音录制、语音检测、本地语音识别、TXT 保存和与录音同步的 SRT 导出；后续计划加入翻译、字幕悬浮显示和本地视频时间轴。

## 启动开发版

需要 Python 3.11 或更新版本。在项目目录中运行：

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -e .
.venv\Scripts\python -m subtitle_app
```

在窗口中选择视频实际使用的输出设备、识别模型和原声语言，再点击“开始录音与识别”并选择 WAV 保存位置。程序先在后台加载本地 Whisper 模型；**首次使用所选模型会先下载，模型就绪后才开始录音**。默认选择 `small`；另可选择速度优先的 `base`，或用于对比的较大模型 `medium`。更大模型在 CPU 上通常更慢，是否更准需要按音频实测。已知原声是中文时，可把“原声语言”设为“中文”，避免每段重新判断语言。播放视频时观察音量条，语音结束并出现约 1 秒静音后，识别文字会逐段显示在窗口中。结束后点击“停止并保存”，最后一段语音也会处理。

录音使用 Windows WASAPI loopback，仅采集选中输出设备正在播放的声音，不采集麦克风。程序会优先混合实际有声音的声道，再持续重采样；保存的 WAV 是 **16 kHz、单声道、16 位 PCM**。WebRTC VAD 负责语音分段，faster-whisper 在 CPU 上识别原文；中文识别结果统一转换为简体字。识别完成后，会自动在 WAV 旁保存 UTF-8 TXT 和 SRT，也可用窗口里的“保存 TXT…”和“导出 SRT…”另存。

## 保存文字和字幕

1. 点击“停止并保存”，等待最后的识别结束。
2. 程序自动保存与 WAV 同名的 `.txt`、`.srt`；窗口会显示路径。TXT 是纯识别文字，SRT 是带起止时间的字幕。已有同名文件时会另存为 `名字-2.txt/.srt`，保留旧文件。
3. 想另存到其他位置，点击“保存 TXT…”或“导出 SRT…”。存在文件时会询问是否替换；保存失败时文字仍留在窗口，可以重试。
4. 需要同步到原视频时，调整“字幕偏移（秒）”，再重新导出 SRT。正数延后、负数提前；修改偏移不会自动改写之前的文件。

SRT 使用模型的词语时间戳断句，并加上片段在原录音中的位置；Silero 移除的配乐或静音间隔会保留在时间轴上。**识别处理耗时不会写进字幕时间。**时间是模型估计值，仍可有误差；极少数缺少词语对齐的片段会回退到模型给出的整段时间。

默认偏移 `0` 与保存的 WAV 同步。例如从原视频第 30 秒开始录音，导出配原视频用的字幕时填 `+30`；若先录音 5 秒才从视频开头播放，则填 `-5`。播放时请保持正常速度并连续播放；系统音频录制无法跟踪播放器的暂停、跳转或倍速，单个全局偏移也无法修复这种时间轴变化。

录音或识别过程中有片段被跳过、识别被中断时，已有结果会另存为带 `-partial` 的文件，表示可能不完整。没有识别文字时不生成空文件。识别期间关闭窗口，会先停止录音、等待最后结果保存后退出。

如果识别结果不理想，先试听保存的 WAV：若 WAV 本身很小声、失真或缺词，先检查输出设备和音量；若 WAV 清晰而文字错误，改用 `small`、指定原声语言并观察是否仍有问题。配乐、朗诵停顿和生僻词仍可能影响 VAD 与 ASR，当前版本尚未做伴奏分离或逐字校对。

后续将按功能逐步复用 [LiveTranslate](https://github.com/TheDeathDragon/LiveTranslate) 的实现，并保留所复用代码的 MIT 版权及许可声明。目前的界面骨架未复制其源代码。

## 开发方向

1. 接入系统音频采集、语音识别和实时翻译，并显示清晰的运行状态。
2. 支持常见云端及本地翻译模型，显示 token 用量和费用。
3. 基于视频音轨时间轴导出校时字幕，再支持字幕封装与烧录。
4. 简化设置、完善界面和 Windows 安装包。

正式产品名称尚未确定，当前包名仅用于开发。

## 离线模型对比

已支持对同一批 WAV 依次比较 small、medium：保留逐段文字、识别耗时、模型配置和参考字错误率，生成可在浏览器打开的 `report.html`。参考文字未核对时明确标为草稿；校对后可以重新评分而无需再次运行模型。

复制 `benchmark.example.json` 为 `benchmark.local.json`，填写录音和参考 TXT 路径后，双击 `compare-models.cmd`。录音、个人测试清单、参考草稿与结果目录默认不提交到 Git。

详细操作、名词解释和实现过程见 [模型对比入门](docs/模型对比入门.md)。
