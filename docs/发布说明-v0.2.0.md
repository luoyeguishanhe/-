# 巴别塔 v0.2.0 · 公开预览版

跨越语言隔阂，让每一句都能被听懂。

这是一个由在校大学生个人开发的独立项目，以适用于各种语音场景的翻译器为长期方向。当前核心功能是本地视频识别与字幕处理、系统声音实时识别与翻译。开发精力有限，会逐步跟进完善。

## 本版内容

- 巴别塔品牌图标、启动介绍页，以及随时可访问的“关于巴别塔”。
- 本地 Whisper small 识别、简体中文输出、TXT/SRT 导出、媒体时间轴与字幕校对。
- 实时可拖动字幕框、外部模型翻译、千问/Ollama/自定义兼容接口。
- 系统声音模式 GPU 优先，失败时明确回退 CPU；识别与翻译各一个等待项，避免长期积压。
- MKV 可开关字幕封装、批量翻译 token 和费用估算。
- 详细开发历程、完整教程、构建说明、GPLv3 和第三方许可。

## 安装与使用

Windows 64 位便携包，完整解压后运行 `巴别塔/巴别塔.exe`。已附带 small 识别模型及 CUDA 运行库，无需安装 Python 或 CUDA Toolkit；GPU 加速仍需兼容的 NVIDIA 显卡和驱动。程序准备好后，在启动页点击“进入巴别塔”。

翻译服务和本地翻译大模型需自行配置，Key 不随包提供。语音识别使用开源免费模型，云端翻译可能收费。GPU 包较大，请保留所有运行资源。打包对应的源码、构建脚本及许可位于本次标签，可从 GitHub 的源码归档获取。

## 已知限制

实时字幕不是零延迟，慢服务仍会造成等待；跟不上时会跳过旧的等待项。直播译文尚不自动保存为 SRT，精细时间校对优先走本地视频流程。文件模式保持 CPU 完整识别配置。没有烧录、自动更新、安装向导或多音轨选择。识别与翻译准确率受语言、配乐、原声质量和外部模型影响。
