# Token 用量与费用

## 怎么使用

1. 重启程序，打开“翻译与封装…”，准备字幕和翻译模型配置。
2. 勾选“启用费用估算”，选择人民币 CNY 或美元 USD。
3. 按服务商报价填写“输入 / 百万 token”和“输出 / 百万 token”。程序没有内置厂商报价，不自动获取价格。
4. 点击“开始翻译原文字幕”。每批返回后，更新本次用量和费用，以及当前工具窗口的累计值。
5. 需要保留记录时，点击“导出用量报告…”，另存为 JSON 文件。

未启用计价会显示“未设置单价”，不是免费。明确免费的本地服务，可以启用计价后将两个单价都填 0。

修改单价只影响下次开始的翻译，已完成任务仍使用当时的单价。切换翻译服务或手动编辑模型名/接口地址会取消计价勾选，避免误用其他模型的价格；开始前请核对后重新勾选。

## Token 数字从哪里来

模型服务通常在响应的 `usage` 中返回：

```json
{"prompt_tokens": 20, "completion_tokens": 10, "total_tokens": 30}
```

- 输入 token：发给模型的内容，包括翻译规则和字幕等，不只计算字幕字数。
- 输出 token：服务返回的生成用量。
- 已知合计：输入和输出相加。程序采用服务报告值，不用汉字数量猜测 token。

程序按批次累计，JSON 数字不是“上一批的累计用量”；界面收到累计快照时替换本次统计，不会把同一批重复加算。

有的接口不返回完整用量，这类调用显示“未知”。超时或连接错误也记为用量未知，因为没有收到结果不代表服务端没有执行或收费。请求已返回明确用量但译文格式错误时，仍统计其 token 和估算费用，即使该批译文未采用。取消时，已返回的批次同样保留统计。

## 费用怎么算

```text
估算费用 = 输入 token ÷ 1,000,000 × 输入单价
         + 输出 token ÷ 1,000,000 × 输出单价
```

例如采用演示价格：输入 2 元 / 百万 token，输出 8 元 / 百万 token。

```text
输入 20 token，输出 10 token
费用 = 20 ÷ 1,000,000 × 2 + 10 ÷ 1,000,000 × 8
     = 0.000120 元
```

这只是计算示例，不是任何厂商的报价。代码使用 `Decimal` 做十进制计算；界面显示六位小数，小于 0.000001 且大于 0 的费用显示为 `<0.000001`，JSON 中保留计算值。

人民币和美元分别累计，不换汇，也不会把两种货币相加。有调用用量未知或没有设置单价时，只显示已知部分，并标出未知调用或未设价次数。

这里是按填写的两项单价计算的估算，不自动应用缓存命中折扣、阶梯价、套餐、赠送额度、税费或优惠。实际付款请以服务商账单为准。本地价格填 0 表示 API 调用费为零，不计算电费和硬件成本。

## 累计范围与报告

本次：最后启动的一个翻译任务。重新开始翻译会重置本次显示，但前一次的用量仍计入当前窗口累计。

本窗口累计：从打开这次“翻译与封装”窗口起，多次翻译的用量。导入其他字幕不会清空已有统计；关闭窗口后不自动保存历史，新窗口从零开始。

导出 JSON 会保存每次任务的接口地址、模型名、UTC 开始时间、用量、采用的单价、币种、估算费用及完整性标记。没有 API Key，也没有字幕原文或译文。未知费用使用 `null`，有明确单价与明确用量算出的零费用则使用 `"0"`，不会混为一谈。

## 实现与验证

- `translation.py`：每个请求返回后发送用量快照；异常请求记录为未知。
- `billing.py`：记录每次任务的计价设置，计算费用与按币种累计，生成报告。
- `subtitle_tools.py`：提供单价设置、本次/累计显示、报告导出；后台处理时锁定计价设置。
- 79 项测试通过，覆盖单位换算、十进制计算、免费与未知、币种分开、网络失败、格式错误的已计费用量、多批次快照和实际本机 HTTP 窗口流程。

界面和计算验证使用本机模拟 API，不产生真实云端费用；报告中的演示 token 与单价不能用于评价真实模型的价格。
