# 视频预览和字幕校对

## 怎么用

1. 启动程序，选择本地视频，等待识别结束。
2. 点击“预览与校对…”，打开独立校对窗口。
3. 点击右侧字幕，视频跳转到对应位置；点击播放试听。
4. 修改右下角的字幕文字、开始和结束秒数，再点击“应用本条修改”。切换字幕时也会自动应用。
5. 时间不合适时，先暂停视频，再用“当前播放位置设为开始 / 设为结束”取当前时间。时间不能与相邻字幕重叠。
6. 点击“另存校对版 SRT…”，保存到一个新文件名，例如 `视频名-校对.srt`。

校对字幕不会改变原识别文字，也不会改写原视频。已有文件不会覆盖；再次保存请换一个名字，例如 `视频名-校对2.srt`。关闭窗口或按 Esc 时，未保存的输入也会触发确认。程序重启后暂时不能加载已存 SRT 继续编辑，请先在外部字幕编辑器中打开已保存文件。

## 从 Python 文件到这些功能

### 1. 主窗口提供入口

`main.py` 创建“预览与校对…”按钮。识别结束、有字幕之后才启用。点击后，把媒体文件路径、字幕列表和全局时间偏移传给 `SubtitleEditor`。校对窗口以模态方式打开：关闭前，主窗口暂停接受操作，避免同时切换识别任务。

### 2. Qt 负责播放

`subtitle_editor.py` 使用三个 Qt 组件：

| 组件 | 工作 |
| --- | --- |
| `QMediaPlayer` | 读取本地文件、播放、暂停、跳转，报告当前时间 |
| `QAudioOutput` | 把声音输出到系统默认设备 |
| `QVideoWidget` | 显示视频画面 |

例如 `player.setPosition(2500)` 表示跳转到第 2.5 秒。播放器使用毫秒，字幕对象使用秒，所以代码要乘除 1000。

### 3. 字幕是独立的数据

每一条字幕用 `SubtitleCue(start, end, text)` 表示，例如：

```python
SubtitleCue(2.6, 4.0, "你将如何书写自己的青春？")
```

表示从 2.6 秒显示到 4.0 秒。校对窗口复制原字幕，修改副本。播放器报告时间变化时，程序找出 `开始 <= 当前时间 < 结束` 的字幕，在视频下方显示；空白间隔不显示字幕。

### 4. 点击和输入通过信号连接

Qt 的“信号”可以理解为通知。点击字幕列表时发出通知，Python 函数收到后先检查当前修改，再读取新条目的开始时间，让播放器跳转。点击应用按钮时，读取文字框和时间框，检查文字非空、起止时间有效、没有与相邻字幕重叠，然后更新列表。

### 5. 保存仍使用已有 SRT 导出模块

`render_srt` 将字幕对象转换为以下格式，再由 `write_export` 写为 UTF-8 文件：

```srt
1
00:00:02,600 --> 00:00:04,000
你将如何书写自己的青春？
```

校对窗口中的时间已包含主窗口偏移，保存时不会再次加偏移。视频处理耗时也不会加进字幕时间。

## 本次如何验证

- 原有 42 项测试通过，新增 8 项测试覆盖时间同步、修改、保存、保存失败保留内容、关闭保护和主窗口接入，共 50 项。
- 用 PyAV 生成真实的 6 秒 H.264/AAC MP4，使用实际 Qt 播放器验证视频帧解码、跳转到 2.5 秒、修改到 2.6 秒及 SRT 输出。
- 验证原始字幕对象没有被修改，已有导出文件不会被替换。

该测试确认本机测试 MP4 的播放与编辑流程，不代表所有视频编码都能预览。当前不包含 SRT 导入、字幕增删合并、翻译或字幕烧录。
